03 / FEATURE ENGINEERING

Multi-modal signal extraction combining lexical patterns and structural heuristics.

TEXTUAL SIGNALS

Word TF-IDF Captures vocabulary, domain-specific terms, and common phishing keywords.
Character TF-IDF Detects misspellings, character-level obfuscation, and script variations.
N-Gram Range Captures local context and multi-word phrases (e.g., "verify account").

URL HEURISTICS

Host Analysis Identifies IP-address hosts and known URL shortener services.
Link Density Measures URL count and total character length of embedded links.
Suspicious Terms Flags keywords like "login", "verify", and "secure" within URL strings.

STRUCTURE & TONE

HTML Markers Detects embedded HTML tags, anchor links, and href attributes.
Urgency Cues Counts exclamation marks, currency symbols, and time-sensitive language.
Case & Digits Analyzes uppercase ratios and digit density to identify spam-like patterns.
TOTAL CONCATENATED FEATURES: ~12,000 DIMENSIONS

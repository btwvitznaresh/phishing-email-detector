05 / Real-Time FastAPI Service

API ARCHITECTURE
  • GET /health Verifies model artifact availability and system readiness.
  • POST /scan Primary inference endpoint. Accepts raw email text via JSON.
  • PYDANTIC VALIDATION Enforces schema integrity and bounded input (max 200k chars).
  • OPENAPI / SWAGGER Interactive documentation automatically served at /docs.
